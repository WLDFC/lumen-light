# ==========================================================
# 方式一：绿色版整合包（推荐，解压即用）
# ==========================================================
# 项目已自带 Node 运行时（runtime/node.exe）和装好的依赖
# （node_modules/），解压后双击 start-server.bat 即可启动，
# 无需安装 Node.js，也无需执行下面的 npm install。
# 适用：Windows x64（捆绑的 node.exe 与原生依赖均为 win-x64）。

# ==========================================================
# 方式二：自行安装 Node + 依赖（开发者 / 其他系统）
# ==========================================================
# 1. 进入项目文件夹
cd lumen-light

# 2. 初始化（会在当前文件夹创建 package.json）
npm init -y

# 3. 安装依赖（会在当前文件夹创建 node_modules/）
npm install express cors ws uuid
