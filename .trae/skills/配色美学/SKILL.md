# LumenLight 深色主题色板

固定深色主题，不支持主题切换。写任何新界面都从本色板取色，不要自创色值。

## 背景层

| 用途 | 色值 | 说明 |
|---|---|---|
| 最底层背景 | `#0f0f12` | 画布底色、页面底色、设置弹窗主体背景、输入框背景、生图节点的下拉与数值框、尺寸/比例双段面板、原生 option 弹层 |
| 面板/容器背景 | `#1b1c21` | 左侧工具栏、右侧面板、设置侧边栏、悬浮控件、LumenDropdown 弹出菜单（LLM 对话框模型/质量） |

层级关系：`#1b1c21` 浮在 `#0f0f12` 之上。需要在面板内再"凹陷"一层（如输入框、内嵌列表）时回落到 `#0f0f12`。

控件分两类：
  - **凹陷层**（`#0f0f12`）：输入框、生图节点的下拉与数值框、尺寸/比例双段面板、原生 option 弹层——比面板深一层，呈"往里凹"的输入语义
  - **浮起层**（`#1b1c21`）：LumenDropdown 弹出菜单（LLM 对话框模型/质量）——与面板同色，靠边框 `rgba(128,128,128,0.3)` 与阴影区分层级，不换底色

CSS 变量已定义在 `css/style.css`，能用变量就别写死色值：

```css
--canvas-bg: #0f0f12;
--icon-bg: rgba(27, 28, 33, 1);   /* 等同 #1b1c21 */
--icon-color: #fff;
--accent: #3b82f6;
```

## 文字层

| 用途 | 色值 |
|---|---|
| 主文字 | `#fff` |
| 次要文字 | `rgba(255, 255, 255, 0.85)` |
| 说明/提示文字 | `rgba(255, 255, 255, 0.5)` |
| 禁用/占位文字 | `rgba(255, 255, 255, 0.3)` |

**纯白 `#fff` 用于**：按钮文字、LLM 对话框消息文字、图标、标题、表单标签 —— 凡是用户需要直接阅读或操作的主体内容。

**半透明白用于**：字段下方的解释文字、空状态提示、次要状态说明 —— 需要视觉后退的辅助信息。

## 边框层

| 用途 | 色值 |
|---|---|
| 通用边框 | `rgba(128, 128, 128, 0.3)` |
| 浅边框（弱分隔） | `rgba(128, 128, 128, 0.2)` |
| 悬停加强边框 | `rgba(128, 128, 128, 0.4)` |
| 聚焦/选中边框 | `rgba(59, 130, 246, 0.6)` |

`rgba(128,128,128,0.3)` 是项目主流用法，新代码统一用它。

不要用 `#1b1c21` 当边框色 —— 它与 `#0f0f12` 对比度太低，在深色底上看不见线。

## 交互层

强调色 `#3b82f6`（蓝），用于主按钮、选中态、聚焦环。

按钮/列表项的悬停与按下，用叠加半透明白，**不要换背景色**：

| 状态 | 色值 |
|---|---|
| 悬停（列表项、次要按钮） | `rgba(255, 255, 255, 0.1)` |
| 悬停（轻量，如分类项） | `rgba(255, 255, 255, 0.05)` |
| 按下/激活 | `rgba(255, 255, 255, 0.18)` |
| 卡片内层底色 | `rgba(255, 255, 255, 0.03)` |
| 进度条/轨道底色 | `rgba(255, 255, 255, 0.1)` |

叠加式悬停的好处：同一套数值在 `#0f0f12` 和 `#1b1c21` 上都成立，不用为每种底色单独配色。

## 状态色

| 状态 | 色值 |
|---|---|
| 成功 | `#22c55e` |
| 错误 | `#ef4444` |

状态色只用于文字、图标、小圆点指示器，不要用作大面积背景。

> 注意：`css/settings.css` 里用的是 `#34d399` / `#f87171`（浅一档），属历史遗留；下拉/菜单面板旧底色 `#1f2937` 已于重构后全量迁移为 `#1b1c21`。新代码统一用上表数值。

# 画布节点设计规范

来源：`css/node.css` + `js/canvas/nodes/BaseCanvasNode.js`（几何常量唯一出处）。新增节点必须长成这一节的模样，不要另起炉灶。

## 尺寸与缩放体系

节点是 DOM 面板（`position: fixed` + `z-index: 997`）浮在画布上，**没有"固定像素"概念**——所有内部尺寸都乘以内容缩放系数 `--ns`，写法一律 `calc(Npx * var(--ns))`：

| 常量 | 值（px，ns=1 时） | 说明 |
|---|---|---|
| `DESIGN_BASE` | 512 | 设计基准：`--ns = min(宽,高) ÷ 512`，框大内容同步变大 |
| `MIN_WIDTH / MIN_HEIGHT` | 1024 | 最小可缩到的尺寸 |
| `DEFAULT_WIDTH` | 2048 | 全部节点默认宽（与画布 2K 图同量级） |
| `DEFAULT_HEIGHT` | 2048（文本/提示词/LLM 生图）、1536（LoRA）、2600（Comfy 生图） | 按内容行数定，超出列表区内部滚动 |
| `HEADER_HEIGHT` | 48 | 标题栏高 |
| `STATUSBAR_HEIGHT` | 40 | 状态栏（端口行）高 |
| `RESIZE_HANDLE_SIZE` | 16（屏幕像素） | 右下角缩放手柄 |

**两种布局模式（`LAYOUT_MODE` 静态常量）**：
- `'world'`（默认）：DOM 布局尺寸 = 世界尺寸，内容按 `--ns` 缩放。**有 textarea 的节点必须用这个**（提示词/文本/LoRA）——textarea 原生光标/选区行为友好
- `'design'`：DOM 布局固定为设计基准尺寸，整体 transform 缩放。**有原生 `<select>` 的节点必须用这个**（两类生图节点）——select 弹出浮层不跟随 CSS transform，固定布局才能让弹层字号与表面文字观感一致；原生 option 字号需乘 `--render-scale`（内容系数 × 视口系数，updateTransform 每帧同步）

## 面板结构模板

```
div.text-node.<类型修饰类>          ← 类名复用：基础 .text-node + 类型类（.image-gen-node 等）
├─ .text-node-header              标题栏：左「英文标题」+ 右「中文徽标」（.text-node-badge）
├─ .text-node-statusbar           端口行：左右端口圆点（无输出端口的节点只有左端口）
├─ .text-node-body / 表单区       内容区（提示词是 textarea，生图类是 .image-gen-form 逐行表单）
└─ .text-node-resize              右下角缩放手柄
```

- `data-id` 必须写上节点 id（事件委托反查）；节点 `appendChild` 到 `document.body`
- 标题命名惯例：英文标题（Generate / Comfy Generate / LoRA Stack）+ 中文徽标（生图节点 / Comfy 生图 / LoRA）
- `overflow: hidden` 禁用——端口圆点要骑在面板边缘外一半；圆角由自身 `border-radius` 保证

## 面板本体样式

| 项 | 值 |
|---|---|
| 背景 | `#1b1c21`（var(--icon-bg)，浮起层） |
| 边框 | `outline: 1px solid rgba(128,128,128,0.3)`——**用 outline 不用 border**：不占布局，textarea 排版宽度不随缩放漂移 |
| 选中态 | outline 变 `#6cebff`（青色，与图片选中边框同色），粗细由 JS 每帧按视口缩放写入 |
| 圆角 | `calc(8px * var(--ns))` |
| 阴影 | `0 4px 16px rgba(0, 0, 0, 0.4)` |
| 标题栏 | 高 48，底色 `rgba(255,255,255,0.03)` 内层浮起，下边框 `rgba(128,128,128,0.2)`；标题 18px/600/#fff，徽标 13px/0.5 白 |
| 状态栏 | 高 40，透明底无边框（与内容区融为一体） |

## 端口圆点（连线锚点）

| 项 | 值 |
|---|---|
| 尺寸 | 15px 圆 + 1.5px 描边 `rgba(15,23,32,0.9)`（外径 18 = JS `PORT_RADIUS` 9） |
| 颜色 | `#6cebff` 青色；悬停 `#9df2ff` |
| 光晕 | `0 0 4px rgba(108,235,255,0.4)`，悬停增强到 `0 0 10px rgba(108,235,255,0.8)` |
| 位置 | 状态栏两端，距边缘 `PORT_INSET` 8px；光标 crosshair |
| 动效 | 只允许 box-shadow 光晕增强，**禁止位移动画**（会和连线锚点错位） |

青色 `#6cebff` 是节点系统的第二强调色（区别于界面蓝 `#3b82f6`）：端口、选中边框、@图片N 引用高亮、数值输入光标 `caret-color` 全用它。

## 表单行（生图类节点）

结构：`.image-gen-form`（纵向 flex，gap 8，padding 10/12，`overflow: visible`——双段下拉向上弹出会被裁切）→ `.image-gen-row`（**标签在上、控件在下**，gap 3）。

| 项 | 值 |
|---|---|
| 行标签 `.image-gen-label` | 12px，`rgba(255,255,255,0.45)`，letter-spacing 0.3px |
| 下拉/数值输入 | 高 38，字号 15，圆角 6，边框 `rgba(128,128,128,0.3)`，底色 `#0f0f12`（凹陷层），字色 #fff，padding 0 8 |
| 模型下拉字号 | 17px——模型名是英文小写，同字号观感比中文小一圈，做视觉补偿 |
| 聚焦 | 边框 `#3b82f6` |
| 数值输入专属 | 隐藏原生 spinner（深色主题下过亮）；`caret-color: #6cebff`；两组「标签+输入框」并排用 `.comfy-param-pair`（各占一半，gap 12） |
| 生成按钮 | 通栏、高 36、圆角 6、`#3b82f6`、字 14px #fff、`margin-top: auto` 沉底；悬停 `#2563eb`；禁用 `opacity: 0.6` |

z-index 层级约定：节点 997 → 顶栏 998 → 右侧面板 999 → 弹窗 ≥1200 → 补全下拉 10000。

## 交互约定（基类统一处理，新节点照抄）

- 面板 mousedown **透传**给 `CanvasInteraction`（`e._canvasNodeTarget = this`）复用选中/拖动；点 textarea 时已编辑态 `stopPropagation` 放行原生行为
- 下拉框/按钮等控件 `stopPropagation` 拦截透传，走原生行为
- 端口 mousedown 带上 `_promptNodePortSide` 后透传，进入连线流程
- 滚轮：编辑态只滚文本，非编辑态缩放画布；右键 `stopPropagation` 不弹画布菜单
- 缩放手柄：hover 换 `nwse-resize` 光标，mousedown 拦截冒泡进入缩放
- 生成按钮用 `isGenerating` 标记防重复提交，生成中 disabled
- 销毁：destroy() 先清理子类资源（镜像层/技能栏/补全/看门狗），再 `super.destroy()`

## 编写检查清单

### 界面通用

- 面板背景用了 `#1b1c21`；输入框、生图节点下拉/数值框、尺寸/比例双段面板等凹陷控件用 `#0f0f12`；LumenDropdown 浮起菜单用 `#1b1c21`
- 按钮和消息文字是 `#fff`，辅助说明是 `rgba(255,255,255,0.5)`
- 边框统一 `rgba(128,128,128,0.3)`
- 悬停用半透明白叠加，不是换底色
- 能用 `css/style.css` 里的 CSS 变量的地方没写死色值

### 画布节点

- 类名复用 `.text-node` 基础 + 类型修饰类，不重写面板底色/边框/阴影/标题栏
- 所有内部尺寸用 `calc(Npx * var(--ns))`，没有任何写死的像素布局尺寸
- 有 textarea 选 `world` 布局，有原生 `<select>` 选 `design` 布局（option 字号乘 `--render-scale`）
- 几何常量（标题栏 48/状态栏 40/端口内缩 8 等）从 `BaseCanvasNode` 静态常量取，不在 CSS/JS 里重复写死
- 强调蓝 `#3b82f6` 只给主按钮和聚焦边框；节点专属青 `#6cebff` 只给端口/选中框/引用高亮/光标
- 控件聚焦边框 `#3b82f6`，禁用态 `opacity: 0.6`
- 交互走基类透传约定（`_canvasNodeTarget` / 控件拦截 / 端口 `_promptNodePortSide`），不在节点里自建选中拖动逻辑
