# 气泡尾巴参数矩阵预览 — 实施计划

## Context

ImageStudio 形状工具的「气泡框」尾巴连续多版调整都不理想（直角三角→贝塞尔圆钩→扁平爪形→月牙形，均与用户提供的漫画截图不符）。纯文字描述+盲调参数的迭代方式效率太低，用户选择「参数矩阵预览」方案：**一次性渲染所有参数组合的缩略图网格，用户看图选号，然后只把选中的参数写进代码**。

## 方案

创建一个自包含的临时 HTML 预览页（不进项目源码，放 `data/pi/workspace/`），网格渲染 24-36 种尾巴参数组合，每种标注编号。用户在浏览器里打开，挑出最接近截图的编号，然后据此更新 `StudioShapeTool.js` 的 `_bubblePath` 常量。

## 实施步骤

### 1. 生成预览页 `data/pi/workspace/bubble-preview.html`

- 单文件、无依赖，双击即开
- 每个格子：一个 300×200 椭圆 + 按该组参数渲染的尾巴（复用 `_bubblePath` 的数学，参数化）
- 参数维度（每个格子 = 一组组合）：
  - **根部半张角 half**：10° / 18° / 26°（3 档）
  - **尾巴长度 tailLen**：0.35 / 0.5 / 0.65（×min(w,h)，3 档）
  - **后掠量 swing**：0 / 0.25 / 0.45（×tailLen，3 档）
  - **凸边外扩 bulge**：1.3 / 1.6 / 1.9（径向外扩系数，3 档）
  - **凹边外扩 concave**：0.95 / 1.1（2 档）
  - 组合方式：不取全笛卡尔积（3×3×3×3×2=162 太多），按「每种 half × 4 组精选的 (tailLen, swing, bulge, concave) 组合」= 12 种 × 2 个变体 ≈ 24-30 格，人工挑选有代表性的组合
- 参考图（用户截图）以 `<img>` 或 base64 内嵌放在页面顶部作对照
- 黑描边 3px、白填充，与实际工具默认样式一致

### 2. 用户挑选

- 用户打开页面回复编号（如「B3 最像」）
- 若都不满意，可指出最接近的编号 + 修改方向（更长/更弯/更尖），我再出一轮微调矩阵

### 3. 写回代码

- 把选中格子的 4 个参数值作为常量写入 `_bubblePath`（`half`、`tailLen` 系数、`swing` 系数、`bulge`/`concave` 系数）
- 同步更新 `_extFor`（外伸 = 尖端合向量，须与 `tailLen`/`swing` 一致，含控制点 ×1.2 保险系数——现有逻辑保持，只改数值）
- 更新文件头注
- 语法检查 `node --check`

## 关键文件

- `js/components/image-studio/StudioShapeTool.js` — `_bubblePath`（尾巴路径）与 `_extFor`（画布外伸），唯一改动点
- `data/pi/workspace/bubble-preview.html` — 新建临时预览页（白名单目录，验证后可删）

## 验证

- 预览页双击打开，网格中所有气泡尾巴完整渲染（无裁切、无破形）
- 用户选中编号 → 写回参数 → Ctrl+F5 刷新 ImageStudio → 画气泡框，形状与所选编号一致
- 四个尾巴方位（rb/lb/lt/rt）各画一个确认旋转对称
- `node --check js/components/image-studio/StudioShapeTool.js` 通过
